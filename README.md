# For My Angel — Chapter 22

A romantic birthday landing page built with HTML, CSS, and JavaScript.

## Run it locally
1. Extract the ZIP.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser. (The VS Code Live Server extension is also a good option.)

## Personalize it before publishing
- In `index.html`, edit the paragraph with `id="letterText"` to write your own message.
- In `script.js`, edit the `reasons` array. Replace the generic examples with 22 real reasons that are personal to her.
- Change the wording in the final wish message inside `script.js`.
- You can add photos later by placing image files in `assets/` and adding `<img>` elements in `index.html`.

## Publish with GitHub Pages
1. Create or sign in to GitHub.
2. Create a **Public** repository named `my-angel-birthday` (or any name you like).
3. Upload `index.html`, `style.css`, `script.js`, and the `assets` folder to the repository root.
4. In the repository, open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then press **Save**.
7. Wait a minute or two. GitHub will show your website URL in the Pages section.

## What each file does
- `index.html`: page structure and content.
- `style.css`: colors, layout, typography, responsive design, and animations.
- `script.js`: the 22 reasons, button interactions, floating hearts, and scroll reveals.

## Important
The page is currently in English and uses a generic sample birthday message. Personalize the text before sharing the link. Google Fonts are loaded online; the page still works without them, using fallback fonts.
